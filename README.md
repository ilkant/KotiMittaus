English:
Program polls your devices via bluetooth 1 minutes half hour. When receives data it drops defice out of polling. Finally it combines all data to one sheet and to a spreadsheet row. If there are no spreadsheet it creates it.

Finnish:
Ohjelma pollaa bluetooth-laitteesi (Contour Care, Omron M7 ja Beurer BT 720) puoli tuntia. Kun se on saanut datan joltain laitteelta, sitä ei enää pollata. Lopuksi ohjelma tekee tiedoista yhden taulukkolaskenta-asiakirjan rivin.
Jos taulukkolaskenta-asiakirjaa ei ole, ohjelma luo sellaisen.

Tällä hetkellä Beurer BT 720 vaakaan saadaan luotettu bluetooth paritus, mutta tieto ei siirry.

Ohjelman käynnistys $ python health.py
